<h1> Лабораторная работа №2.4 "Асинхронный исполнитель задач" </h1>
<hr>
<p>Программа содержит асинхронный исполнитель, выполняющий задачи из файла</p>

<p>Поддерживает следующие команды:</p>
<ul>
    <li> python -m src.main - запуск исполнителя задач </li>
    <li> add_source [filename] - запуск обработки задач из файла </li>
    <li> list - выводит выполняемые задачи</li>
    <li> exit - завершение работы исполнителя задач</li>
    <li> pytest --cov=. --cov-report=term-missing - запуск тестов </li>
</ul>

<h2> Основные компоненты </h2>

<h3>FileSource</h3>
    <p>При инициализации принимает имя файла, в котором содержатся задачи. Во время итерирования асинхронно открыает файл с задачами, читает их построчно и возвращает при корректности данных. При некорректных данных выводит сообщение об этом.</p>

<h3>Sheduler</h3>
    <p>При инициализации создаёт массив для выполняемых задач. При вызове run запускает асинхронный ввод и читает команды из него. Команда list выводит содержимое списка выполняемых/недавно выполненных задач. Команда exit прерывает все задачи и закрывает консоль. Команда add_source инициализирует FileSource по имени переданного файла, в процессе итерации по которому новые задачи добавляются в массив исполнителя и запускают асинхронное выполнение. После окончания выполнения задачи выводится сообщение о завершении.</p>
