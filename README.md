<h1> Лабораторная работа №2.4 "Асинхронный исполнитель задач" </h1>
<hr>
<p>Программа содержит асинхронный исполнитель, выполняющий задачи из файла или генератора</p>

<p>Поддерживает следующие команды:</p>
<ul>
    <li> python -m src.main - запуск исполнителя задач </li>
    <li> file [filename] - запуск обработки задач из файла </li>
    <li> file_name [filename] [name] - запуск обработки задач из файла с фильтром по имени </li>
    <li> file_status [filename] [status] - запуск обработки задач из файла с фильтром по статусу </li>
    <li> file_priority [filename] [priority] - запуск обработки задач из файла с фильтром по приоритету </li>
    <li> gen - запуск обработки задач из генератора </li>
    <li> gen_name [name] - запуск обработки задач из генератора с фильтром по имени </li>
    <li> gen_status [status] - запуск обработки задач из генератора с фильтром по статусу </li>
    <li> gen_priority [priority] - запуск обработки задач из генератора с фильтром по приоритету </li>
    <li> list - выводит выполняемые задачи</li>
    <li> exit - завершение работы исполнителя задач</li>
    <li> pytest --cov=. --cov-report=term-missing - запуск тестов </li>
</ul>

<h2> Основные компоненты </h2>

<h3>Task</h3>
    <p>Класс задачи. Метод create_task возвращает задачу, созданную из данных словаря. Метод run имитирует рабочий процесс задачи, делая задержку и затем меняя свой статус. Поля задачи контролируются дескрипторами.</p>

<h3>Дескрипторы</h3>
    <p>Дескриптор ImmutableDescriptor, контролирующий поля id, name и body задачи, разрешает инициализацию поля со строчным типом и просмотр поля и запрещает изменение(исключение SetAtrTaskException) и удаление(исключение DelAtrTaskException) поля.</p>
    <p>Дескриптор StatusDescriptor, контролируюший поле status задачи, разрешает инициализацию поля с целочисленным типом со значением от 0 до 4(исключение SetAtrTaskException), просмотр поля и изменение в соответствии с типом и допустимыми значениями(исключение SetAtrTaskException) и запрещает удаление(исключение DelAtrTaskException).</p>
    <p>Дескриптор PriorityDescriptor, контролируюший поле priority задачи, разрешает инициализацию поля с целочисленным типом со значением от 0 до 4(исключение SetAtrTaskException), просмотр поля и изменение в соответствии с типом и допустимыми значениями(исключение SetAtrTaskException) и запрещает удаление(исключение DelAtrTaskException).</p>

<h3>TaskSource</h3>
    <p>Модель источника. Задаёт контракт get_tasks для всех источников. Соответствие проверяется по duck_typing.</p>

<h3>FileSource</h3>
    <p>При инициализации принимает имя файла, в котором содержатся задачи. Во время итерирования асинхронно открыает файл с задачами, читает их построчно и возвращает при корректности данных и соответствии фильтру. При некорректных данных выводит сообщение об этом.</p>

<h3>GeneratorSource</h3>
    <p>Во время итерирования асинхронно генерирует и возвращает задачи при корректности данных и соответствии фильтру. При некорректных данных выводит сообщение об этом.</p>

<h3>Sheduler</h3>
    <p>При инициализации создаёт массив для выполняемых задач. При вызове run запускает асинхронный ввод и читает команды из него. Команда list выводит содержимое списка выполняемых/недавно выполненных задач. Команда exit прерывает все задачи и закрывает консоль. Команды file... и gen... инициализируют источники задач, в процессе итерации по которым новые задачи добавляются в массив исполнителя и запускают асинхронное выполнение. После окончания выполнения задачи выводится сообщение о завершении.</p>
